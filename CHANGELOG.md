# Изменения

Публичная история заметных изменений. Внутренние детали разработки и
диагностики сюда не входят — полная техническая история ведётся отдельно.

## 15.09.2026

- **Панель (6.44).** Починено удаление адреса/домена из «Своих маршрутов»,
  если запись оказалась в другой вашей группе — раньше панель отказывала и
  просила консольную команду, теперь убирает сама.
- **Панель в LuCI.** На нативном OpenWrt панель теперь можно поставить как
  обычный пакет (`apk add meridian-web luci-app-meridian` или
  `opkg install meridian-web`) — появляется пункт «Службы → Меридиан».
- **Движок маршрутизации (1.34–1.35).** Устранены зависания DoT-запросов
  через туннель (не хватало подгонки размера пакета для нашего канала).
- **Установщик.** Самостоятельно чинит нехватку HTTPS и сертификатов на
  роутерах Entware, где не хватает пакетов `wget-ssl`/`ca-certificates`.
- **Доступность.** Установщик и стартовая команда бота теперь пробуют
  несколько независимых источников (основной сайт, GitHub, резервный сервер)
  по очереди — если один недоступен из вашей сети, используется следующий.

## Раньше

Сжатая история более ранних версий будет дополняться сюда постепенно.
